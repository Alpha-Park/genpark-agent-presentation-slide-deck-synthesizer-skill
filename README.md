# genpark-agent-presentation-slide-deck-synthesizer-skill

Post-trained consultant-grade presentation generator structuring business topics into cohesive slide decks with golden pyramid layouts.

## Architecture
- **Input**: Long-form research reports, strategic memos, or prompt objectives.
- **Engine**: Layout AST compiler structuring content into title hero, executive summary, and multi-column comparison blocks.
- **Output**: Boardroom-ready slide AST with speaker notes and timing estimates.
